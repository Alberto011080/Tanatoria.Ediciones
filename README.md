# Tanatoria — Ediciones de lo oscuro

Sitio web de Tanatoria, sello editorial de narrativa y cómic de terror gótico en español, con Edgar Allan Poe como referencia estética.

Este repositorio contiene la maqueta del sitio: página de inicio, catálogo, servicios y sumisión de manuscritos. Está publicado con GitHub Pages directamente desde este repositorio.

## Estructura

- `index.html` — página de inicio (quiénes somos)
- `catalogo.html` — catálogo y plantilla de ficha de libro
- `servicios.html` — servicios editoriales
- `sumision.html` — bases de sumisión de manuscritos
- `raven.jpg`, `dracula-cover.jpg` — imágenes usadas en el sitio

## Estado

En construcción — todavía no hay títulos publicados. La convocatoria de manuscritos está abierta.
